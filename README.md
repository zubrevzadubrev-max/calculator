# 🧮 Красивый калькулятор на Python

Современный калькулятор с графическим интерфейсом, созданный с использованием Tkinter. Имеет стильный дизайн в темных тонах и поддерживает базовые математические операции.

## ✨ Особенности

- 🎨 Современный минималистичный дизайн
- 🖥️ Удобный графический интерфейс
- ⌨️ Поддержка клавиатурного ввода
- 📜 История вычислений
- 🎯 Адаптивный размер окна
- 🌈 Анимация кнопок при наведении
- 📱 Фиксированный размер для удобства использования

## 🚀 Возможности

- Базовые операции: сложение, вычитание, умножение, деление
- Работа с процентами
- Смена знака числа (±)
- Удаление последнего введенного символа
- Полная очистка экрана
- Обработка ошибок (деление на ноль, неверное выражение)

## 📦 Установка и запуск

### Требования
- Python 3.6 или выше
- Tkinter (обычно входит в стандартную установку Python)
